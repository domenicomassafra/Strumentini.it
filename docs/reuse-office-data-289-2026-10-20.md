```sh
git rev-parse HEAD
git ls-files 'src/engines/table/**' 'src/engines/ooxml/**' 'src/engines/office-local/**' 'src/engines/developer-web/**'
wc -l src/engines/table/{csv,operations,advanced,spreadsheet-interchange,xml-interchange,xml-parser-adapter}.ts
node -e 'const p=require("./package-lock.json").packages;for(const n of ["papaparse","fflate","read-excel-file","write-excel-file","docx","fast-xml-parser","yaml","smol-toml","turndown","arquero"]){const x=p["node_modules/"+n]; console.log(n,x?.version??"NOT_INSTALLED")}'
rg -n 'papaparse|fast-xml-parser|import\("docx"\)|import\("turndown"\)|import\("smol-toml"\)|read-excel-file|write-excel-file' src/engines src/tools
```

Per ogni eventuale **nuova** adozione su issue distinta: pin/npm integrity + tag/commit/licenza e transitivi/notice; fixture valide/ostili, confronto di fedeltà/abort/privacy, bundle/memoria/CSP, output riaperto da oracle indipendente, build/CI e consumer reali.
