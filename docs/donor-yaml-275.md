## Runtime and semantics

- **Lazy, local, no egress.** `src/engines/developer-web/yaml-adapter.ts` imports `yaml` dynamically inside `yamlFormatterOperation`; Astro/Vite emits a separate same-origin chunk (`browser.<hash>.js`, **96,207 B / 29,644 B gzip**) that is requested only on the first formatting request, never during page load. No fetch, upload, storage or telemetry is added; the existing local-only result contract is unchanged.
- **Bounded inputs.** `assertInputSize` keeps the 1,000,000-character cap. A linear pre-scan refuses flow nesting beyond `MAX_YAML_DEPTH` (32) before the donor tokenizes; a post-parse walk enforces the same depth for block nesting, rejects non-finite numbers and rebuilds records with defined own properties so `__proto__`/`constructor` keys cannot reach the prototype chain. Aliases are allowed up to `maxAliasCount` 100 (donor bound) and the alias bomb is refused. Cancellation (`AbortSignal`) is checked before the import and after parse.
- **Explicit refusals instead of guessing:** custom and non-core standard tags (`!tag`, `!!binary`, `!!timestamp`, `!!set`, …), YAML merge keys (`<<`), complex (collection) mapping keys, multiple documents, duplicate keys and tab indentation all fail with `INVALID_YAML`/`UNSUPPORTED_YAML`; nothing is silently truncated or coerced.
- **Deterministic output.** YAML 1.2 core schema, insertion order preserved, `lineWidth: 0` (no folding), `blockQuote: "literal"` (multi-line strings stay readable block scalars), `aliasDuplicateObjects: false` (no generated anchors). Values are byte-identical to the historical formatter on every fixture it already accepted, with three deliberate improvements: quoted keys that used to emit invalid YAML (`colon: key: v`), trailing spaces that used to be lost, and YAML 1.2 numeric forms (`1e3`, `0x1f`, `0777`) that used to be strings. Two fixtures the old parser refused now work: literal block scalars and anchors on block mappings.
- **Fallbacks kept.** The historical parser/formatter stays exported (`parseYaml`, `formatYaml`, `legacyYamlFormatterOperation`): it still runs the JSON↔YAML converter and the `indent = 0` option (the donor refuses a zero indent); `yamlFormatterOperation` reports the fallback in `warnings` for that case.
- **Rollback.** Revert this merge commit: `index.ts` returns to the synchronous `structured-data` route, `yaml-adapter.ts`, the fixture corpus, the acceptance/benchmark scripts and this document are removed, `yaml` leaves `package.json`/`package-lock.json`, and `npm run catalog:build` regenerates the index. No data or runtime migration is involved.
