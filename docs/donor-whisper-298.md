## Model and rights (separate from runtime)

- Hugging Face [`Xenova/whisper-tiny`](https://huggingface.co/Xenova/whisper-tiny), repository commit/revision `5332fcc35e32a33b86612b9a57a89be7906102b1`, model card **apache-2.0**; multilingual, derived from [`openai/whisper-tiny`](https://huggingface.co/openai/whisper-tiny) whose model card also declares **apache-2.0**. This is the *multilingual* model; no English-only `*.en` variant.
- Quantized ONNX LFS payloads at that exact revision, with upstream SHA-256 and size: `onnx/encoder_model_quantized.onnx` `fd9d995b9dcb0520f0dbf6cf68651af639fc385f594d9d876e69ca2802dc438e` (10,124,910 bytes), `onnx/decoder_model_merged_quantized.onnx` `6c0c125986b007d2e3734bec84c18bda0152071b90b87fadac6d7764499927a0` (30,727,765 bytes). Other model metadata, generation settings and tokenizer are loaded at the same immutable revision. These hashes come from the host's Git LFS manifests; browser runtime loading currently pins the commit but **does not independently hash-check each downloaded weight**.
- Both files were also downloaded independently from those exact immutable `resolve/<commit>` URLs on 2026-10-19 and SHA-256 checked byte-for-byte against their corresponding Git LFS hashes. The browser pipeline still relies on Hugging Face transport and its fixed revision rather than a separate in-browser integrity verifier.
- Only a deliberate click triggers the dynamic module Worker, WASM and model download. Model origin: `https://huggingface.co/` with immutable commit revision (redirected weight/CDN hosts controlled by Hugging Face); runtime WASM: the versioned `https://cdn.jsdelivr.net/npm/@huggingface/transformers@4.3.1/dist/` default documented by upstream. The normal browser HTTP cache may retain assets; there is no added service worker, audio upload or backend transcription endpoint. Cold/warm asset and inference timing is displayed as browser-observed timing, not a promised benchmark.
- Browser path uses WASM `q8`. WebGPU is withheld pending compatibility proofs (upstream #1298 iOS, #740 Android, #1684 timestamps); Safari/Android, 4-GiB devices and subtitle cue accuracy remain uncertified. Session ends on Worker termination, cancel, pagehide or file change. Pause takes effect **at the next 15-second segment boundary**, after the current inference finishes; close/cancel is immediate Worker termination. TXT only: SRT timestamps not asserted.

## Independent Italian corpus

[`PolyAI/minds14`](https://huggingface.co/datasets/PolyAI/minds14), commit `40ce77cb32a384e4d50a568e1ec39ac804019d33`, license **CC-BY-4.0**, split `it-IT/train`, sample index 1, ground-truth provided by dataset: “Buongiorno Vorrei depositare denaro sul mio conto corrente Come devo fare per cortesia”. Original G.711 mu-law stream decoded to true mono 16-kHz PCM16 WAV via FFmpeg **test-fixture generation only**. Checked-in `tests/fixtures/whisper-298/italian-minds14-1.wav`, SHA-256 `0e56ea58e997634f970d1ac39efc6f68459474211435be858fe7b53006f974aa`, duration 8.42s (ffprobe); authorship/transcription from dataset, CC-BY attribution to PolyAI and its speakers. Actual audio fixtures never leave the browser in the site implementation.

The tests cover strict decoder, authentic Italian waveform, memory/duration bounds, unsupported codecs, corrupted RIFF and silence. Browser ASR/network verification is reported separately in issue #298. There is no false claim that passing WAV decode proves model transcription.

The 2026-10-19 local Chromium test on the real 8.42 s Italian MINDS-14 clip succeeded end-to-end with Whisper: “Buongiorno, e senti a fine, si può considerare di un altro subito con il reente. Come devo fare per curteri?”. This differs considerably from the independent reference; punctuation-stripped, lowercased word edit distance is 15 against 13 reference words, **WER 115.4%**. This demo therefore proves an actual model result but **does not pass an accuracy/Gold claim**. Remote requests observed: HTTPS GET only to `huggingface.co`, `us.aws.cdn.hf.co` and `cdn.jsdelivr.net`; no audio POST/PUT. The Playwright acceptance also confirms no eager model request, immediate Worker cancellation, network-denied fail-closed state and no fabricated text. The exact model-backed test is opt-in (`node tests/whisper-298.browser.mjs --full`) because it downloads tens of MiB; the fast browser contract runs without `--full`.

Cloudflare static dry-run initially rejected an unneeded ONNX Runtime `.asyncify` fallback artifact (25.6 MiB). The Vite build removes only that generated fallback asset; the installed Transformers.js ONNX browser runtime resolves its actual WASM from the pinned versioned jsDelivr origin. `npm run build` and `npm run deploy:check` now pass, with no production deployment performed.
