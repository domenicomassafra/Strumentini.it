# STR-158 — Italia, fonti e rollover annuale

Il registro dei consumer è `src/reference-data/italy/freshness-consumers-158.ts`. Il report di `src/reference-data/italy/freshness-158.ts` collega ogni consumer a fonte ufficiale, versione, owner, anno supportato, data di verifica e prossima condizione di review. Per gli snapshot annuali include anche `nextReviewAt`.

Il comando `npm run italy:freshness:158 -- --check` verifica l'esistenza dei file consumer e dei metadati delle fonti. Restituisce errore se un dataset marcato *current-year* non è stato verificato per l'anno civile italiano oppure la review annuale è scaduta. `--as-of 2026-12-31 --check` simula una scadenza senza aggiornare alcuna fonte: deve fallire; in data 19/10/2026 la stessa verifica deve passare. Le funzioni di calcolo condivise per IRPEF lorda nazionale, INPS e festività 2026 chiamano il gate direttamente, per cui anche i rispettivi consumer UI ereditano il blocco. Il limite di review scelto per i dataset annuali è il **31 dicembre dell'anno supportato**; la data civile è calcolata nel fuso Europe/Rome.

Le versioni esplicitamente storiche rimangono disponibili offline: IRPEF e INPS 2025, coefficiente forfettario ATECO2007 2025, finestra IVA 13–31/12/2025, addizionali Puglia/Bari 2025, TFR FOI dicembre 2025, bollo fatture 2024. Non sono promosse a regole 2026. L'inventario documenta anche gli schemi FatturaPA e la geografia amministrativa come fonti da rivalutare a ogni cambio ufficiale: **non esiste un controllo automatico del sito sorgente per questi eventi**. Il gate valuta esclusivamente gli snapshot e le date registrati nel repository; l'intero source pack fiscale STR-117 rimane bloccato per l'uso normativo generale.

Fonti ufficiali collegate dai record: [Normattiva — legge 199/2025](https://www.normattiva.it/eli/stato/LEGGE/2025/12/30/199/CONSOLIDATED) per gli scaglioni IRPEF 2026; [INPS — circolare 8/2026](https://www.inps.it/content/dam/inps-site/it/scorporati/circolari-e-messaggi/2026/02/Circolare_15153/Allegati/16573_Circolare-numero-8-del-03-02-2026.pdf) per Gestione Separata 2026; [Normattiva — legge 151/2025](https://www.normattiva.it/uri-res/N2Ls?urn:nir:stato:legge:2025-10-08;151) per le festività 2026; [ISTAT — prezzi al consumo dicembre 2025](https://www.istat.it/comunicato-stampa/prezzi-al-consumo-dicembre-2025/) per la rivalutazione TFR 2025. Gli altri URL ufficiali e i file sorgente registrati sono recuperabili dal report.
