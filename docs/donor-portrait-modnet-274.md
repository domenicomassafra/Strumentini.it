# #274 — MODNet portrait-only alpha matting: provenance and NO_GO (2026-10-19)

## Scope and reuse

This is an **opt-in, noindex, experimental browser laboratory** at `/laboratorio/scontorno-ritratti/`, not a Gold tool or an authorized public production release. Existing conversion/crop/resize/tools are not modified. Unlike a flat background compositor, the worker performs actual portrait matting using the existing `@huggingface/transformers@4.3.1` Apache-2.0 dependency, with `onnxruntime-web` MIT, and returns PNG RGBA. No server-side image processing, no provider upload or MiniPC dependency. Inputs are limited to portraits of persons; generic object extraction is outside the donor model's scope.

## Browser contract and evidence boundaries

An explicit click starts a module Worker, all model and WASM assets are same-origin paths (no CDN), and `allowRemoteModels=false`, `local_files_only=true` prohibit model fallbacks. Only GETs to the site's own model/runtime paths are needed. A warm-cache retry with `/models/**` requests blocked successfully re-created a PNG in Chromium and Firefox; a fresh browser context with that path blocked failed closed and produced no output. Browser cache is **not guaranteed persistent storage** or a service worker: repeatability depends on the browser's state, and true airplane-mode page navigation remains unproven. Cancellation kills the Worker and its model memory. Timeout: 120 seconds. Input JPEG/PNG/WebP up to 8 MiB, max 1600 px each side, max 2 million pixels; devices reporting <4 GiB memory are refused. Unknown memory is a hardware proof gap, not evidence of suitability. Output gets independent PNG header and browser-decode dimensional verification, with alpha histogram and visual preview; a degenerate matte is refused. No metadata container is copied to PNG.

Fixtures: real publicly available Pexels portraits ([5965592](https://www.pexels.com/photo/5965592/), [774909](https://www.pexels.com/photo/774909/), [220453](https://www.pexels.com/photo/220453/)), obtained 2026-10-19 at width 768 under the [Pexels License](https://www.pexels.com/license/) (not facial identities or private user files). Local fixture hashes, respectively: `6702252f7f2a15d9d68c0101d01ced1d301d8625709b8773a7744da5f7d19242`, `fadee2311305700e0fe1fdac13b0ff9a053db79438c197d679a4eceb671ebae3`, `5c71ebfc46c192d68daf15ea0dc10e744a0a9c6dbd79ada25c8658b976e5c89a`. Independent conservative human-inspected oracle `tests/fixtures/portrait-modnet-274/annotation-points.json` selects 4 person and 4 background interior coordinates per image, separate from model predictions. Browser decoded PNG results classified **24/24** of those points correctly in both Chromium and Firefox (accuracy 100% vs 50% for the better of the two constant-alpha baselines, threshold >=180 foreground / <=32 background). Pixel masks also contain hundreds of thousands of mixed-alpha pixels. These are **not** pixel-accurate full-frame ground-truth masks: hair-boundary precision, true transparent-input preservation, and complex-background segmentation quality need independently annotated reference masks and real-device observations.
