## Riuso confermato

La UI sperimentale usa Tesseract.js 7.0.0 e il WASM già distribuito
per #246. Modello italiano sempre nello stesso sito, da
`public/ocr-246/lang/ita.traineddata.gz`, provenienza e licenza nel
registro originale #366. L'adattatore #395 riusa preflight PNG/APNG,
limiti di memoria, rotazione, cancellazione e worker lifecycle #246;
cambia soltanto la lingua caricata nel worker per EN. Il preflight
pubblico #246 rimane IT-only per non alterare gli altri consumer.

[`@tesseract.js-data/eng@1.0.0`](https://registry.npmjs.org/@tesseract.js-data/eng/-/eng-1.0.0.tgz),
`package/4.0.0/eng.traineddata.gz`, scaricato dal registry il 23/10/2026.

Il package npm riporta licenza MIT per il distributore; quel metadato
non sostituisce la licenza Apache-2.0 del modello originale.

Il modello sta sotto `public/ocr-395/lang`. Il writer seriale #366 ha
integrato il suo pin, la sorgente immutabile, il COPYING upstream esatto
e la verifica del contenuto decompressato nel registro esistente.
Il gate rifiuta un modello senza pin o con distribuzione npm estranea;
questa coerenza dei byte non sostituisce acceptance browser o release.

La pagina iniziale carica zero asset OCR. IT si carica soltanto al run IT;
il pack EN viene richiesto con URL stesso origin
`/ocr-395/lang/eng.traineddata.gz` soltanto al run EN. Cache Tesseract
`none`; né PNG né testo sono spediti a servizi esterni.
Confidence del motore: score 0–100 **non calibrato** riferito solo
alla prima estrazione; qualsiasi correzione rimane una bozza umana.
Nessuna score/rotazione/degrado rende il risultato autorevole.

La variante ruotata ha SHA-256
`9ea6d40ba5e594b8e69a4b3fc1362b08f69f2f9d73b8994778f200c2c73c14a4`;
la degradata a bassissimo contrasto
`8bd4490ee27b7e678c36ce8722b1c105e0306435f706678514ed675ea0ecd431`.
I file sono fixture sintetiche etichettate, non campioni rappresentativi
di scansioni reali. Oracle browser: confronto sul testo etichettato,
TXT riaperto dai byte e browser request log per controllare il caricamento.
La robustezza su una popolazione reale di scansioni diverse resta **NOT_RUN / NO_GO**.
Nessuna prova dispositivi fisici o promozione #271/Gold è rivendicata.
