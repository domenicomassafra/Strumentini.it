## Functional gate and upstream feedback

The [upstream package README](https://github.com/WebAV-Tech/WebAV/blob/1be5d00629f4c855182fac37ba3dc32b5eedbf54/packages/av-cliper/README.md) documents `MP4Clip` for decoding and `Combinator` MP4 output, without an equivalent WebM VP8/Opus demux/clip pathway. [Upstream project compatibility](https://github.com/WebAV-Tech/WebAV) names Chrome/Edge, not the required parity in Firefox/WebKit. [WebAV #439](https://github.com/WebAV-Tech/WebAV/issues/439) documents broken/delayed playback in Firefox/VLC; [#438](https://github.com/WebAV-Tech/WebAV/issues/438), covering codec/mux support, remains open as of this review.

The [20 October live Chromium spike](https://github.com/domenicomassafra/Strumentini.it/issues/296#issuecomment-6286708905) observed `MP4Clip stream is done, but not emit ready` on WebM VP8/Opus; MP4 H.264/AAC was readable, but AAC encoding was unsupported in that browser, and video-only MP4 output lost audio and gained ~67 ms over 2 s. Those prior observations are not repeat tests in this document's commit. No confirmed output for WebM input, MP4 with synchronized AAC, bounded trim/crop, Firefox/WebKit, mobile memory, cancellation and independent real-file comparison. The [bilibili/web-demuxer](https://github.com/bilibili/web-demuxer) alternative has an MIT main codebase **but FFmpeg-derived LGPL code under `lib/`**, so cannot be treated as a verified permissive-only drop-in.

**Decision:** `NO_ADOPT` / production `NO_GO`. Owner option B in [#126](https://github.com/domenicomassafra/Strumentini.it/issues/126) already removed the old MPL worker and consumer in [PR #342](https://github.com/domenicomassafra/Strumentini.it/pull/342). A new candidate must first prove all required container/codec inputs and outputs with independent media + ffprobe/browser decoder, cross-browser tests, typed unsupported paths, cancellation, CSP/zero-upload, memory, notices and source/artifact mapping. Rollback baseline is the existing retired functionality: never reinstate Mediabunny MPL or bypass `scripts/forbidden-codecs-126.ts` to manufacture equivalence. No runtime, dependency, lockfile, generated asset, build or deploy changes in this documentation-only evaluation.
