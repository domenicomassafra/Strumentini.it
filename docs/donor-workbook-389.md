# STR-389 — donor e perimetro workbook XLSX (20 ottobre 2026)

Il pacchetto [`fflate@0.8.3`](https://github.com/101arrowz/fflate/tree/v0.8.3), MIT, tag Git `a661bab4c135c368b6e68af3be1904f89ed070cf`, è **già installato e bloccato** nel `package-lock.json`: ZIP codec di questo nuovo percorso, dopo il controllo OOXML già esistente `analyzeOoxmlPackage`. Repository upstream interrogato via GitHub API il 20/10/2026: licenza MIT e ultimo push osservato 16/05/2026. Nessuna dipendenza nuova e nessun payload terzo copiato in sorgenti locali.

[`read-excel-file@9.3.10`](https://github.com/catamphetamine/read-excel-file) e [`write-excel-file@4.1.1`](https://github.com/catamphetamine/write-excel-file) restano i donor di import/export già presenti per conversioni CSV/XLSX. Il relativo editor `#146` conserva il proprio rifiuto delle formule e non viene modificato nel comportamento CSV. Il nuovo percorso workbook legge e riscrive soltanto `sheetData` nel contenitore XML esistente, conserva gli altri membri e ricalcola un sottoinsieme matematico locale dichiarato prima di scrivere `<f>` e `<v>`.

Candidati valutati il 20/10/2026 con GitHub API: [`exceljs`](https://github.com/exceljs/exceljs) licenza MIT, ultimo push 21/01/2025, offre un modello di workbook più ampio ma non è un oracle di valutazione delle formule; introdurlo aumenterebbe superficie e dipendenze per un percorso ristretto. [`HyperFormula`](https://github.com/handsontable/hyperformula) aggiornato il 20/10/2026, campo licenza GitHub `NOASSERTION` (licenze differenziate da verificare): non adottato senza una decisione/licenza adeguata. Nessun motore remoto, script, macro o valutatore dinamico viene usato.

**Supporto verificabile:** workbook locale con un solo worksheet, celle testuali/numeriche (fino a 15 cifre decimali affidabili), riferimenti A1, quattro operazioni aritmetiche, parentesi e `SUM(A1:B3)` con ciclo e divisione per zero rifiutati. Le formule non supportate, i riferimenti esterni, le macro, le formattazioni complesse e le strutture OOXML non preservabili sono `NO_GO` espliciti; i risultati in cache del workbook sorgente non diventano autorità. Limiti: file 10 MiB, foglio 200 × 32 celle, formula 512 caratteri, export 20 MiB. Questo perimetro non equivale a compatibilità universale con Excel.
