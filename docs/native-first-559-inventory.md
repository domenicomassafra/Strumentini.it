# Native-first #559 — source inventory (2026-11-03)

Scope: Strumentini.it source, 3 November 2026, `origin/main` at `0e6f05cb8f6cc6a58ef6e60fd07192c686d3e1b4`. This repo ships one static Astro site and an optional Cloudflare Worker; it does not install Hermes, Orca, CoS, OmniRoute, systemd or launchd services on Studio, MiniPC, MateBook or Air. Thus application build/test changes have a Studio consumer, Actions changes have a GitHub runner consumer, and Worker changes have a Cloudflare consumer. There is no host-specific runtime to modify on the other three machines for the changes in this PR.

The path census covers **368 source paths**: 10 root configurations, 2 Git hooks, 20 GitHub workflows, 272 scripts (excluding the removed server script), 28 checked-in tool pages, 5 route-wrapper generator inputs, 14 browser workbench/persistence modules, 17 Worker files (including 4 migrations). The 256 generated tool pages materialize during `npm ci`; they are not independent hand-written configuration files. The path-level annexes [`paths-1`](native-first-559-paths-1.md), [`paths-2`](native-first-559-paths-2.md), [`paths-3`](native-first-559-paths-3.md), [`paths-4`](native-first-559-paths-4.md), and [`paths-5`](native-first-559-paths-5.md) enumerate every one of these source paths. `NATIVE` means native mechanism already used; `REPLACE` means a redundant wrapper removed here; `GAP` means remaining application or verification behavior is additional to the platform feature. The 224 formerly open REVIEW paths have been read and individually classified in the annexes: 223 GAP, 1 NATIVE. Each per-path row includes a SHA256 prefix binding the observation to the inspected source. Python `-m http.server` is the native Python stdlib file server; the surrounding standalone browser checks, fixtures and receipts have product-specific behavior. Playwright Test `webServer` needs migration into the Playwright Test runner and cannot replace these standalone Node/tsx CLI invocations in place.

## Per-path audit completed on 2026-11-03

- All 368 source paths now have final classifications. The 224 formerly REVIEW rows are 223 GAP and one NATIVE, each with observed native mechanisms and a SHA256 prefix. The 76 Python stdlib HTTP server invocations belong to standalone acceptance scripts; those scripts additionally perform browser assertions, fixture setup, failure checking and receipts. The Image Resize physical server that was only a separate launcher was replaced with native Astro preview in this PR.
- Python's native HTTP server is already used in the standalone scripts. Playwright Test webServer belongs to the Playwright Test runner; converting the legacy standalone Node/tsx CLIs requires retaining their product-specific assertions, CLI contracts, browser engines, custom origins and receipts. The tested Vite preview substitution was unsuitable as a universal replacement: a missing URL returned HTTP 200 on Studio. No acceptance logic is discarded merely to remove a subprocess.
- The scheduled fiscal workflow relies on native GitHub Actions run failures and opt-in notifications. A user's notification preferences and the next scheduled run remain external observations, not local test proofs.
- Sources verified 2026-11-03: Python http.server (<https://docs.python.org/3/library/http.server.html>), Playwright Test webServer (<https://playwright.dev/docs/test-webserver>), Astro preview (<https://docs.astro.build/en/reference/cli-reference/>), Vite 8.3.5 native CLI help on Studio, Node child_process and fs (<https://nodejs.org/api/child_process.html>, <https://nodejs.org/api/fs.html>). Source evidence is bound per row in the annexes.

No third-party code was adopted. No change to public production, stored credentials, accounts, personal files, or device data is part of this PR.
