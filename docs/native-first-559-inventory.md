# Native-first #559 — source inventory (2026-11-03)

Scope: Strumentini.it source, 3 November 2026, `origin/main` at `0e6f05cb8f6cc6a58ef6e60fd07192c686d3e1b4`. This repo ships one static Astro site and an optional Cloudflare Worker; it does not install Hermes, Orca, CoS, OmniRoute, systemd or launchd services on Studio, MiniPC, MateBook or Air. Thus application build/test changes have a Studio consumer, Actions changes have a GitHub runner consumer, and Worker changes have a Cloudflare consumer. There is no host-specific runtime to modify on the other three machines for the changes in this PR.

The path census covers **368 source paths**: 10 root configurations, 2 Git hooks, 20 GitHub workflows, 272 scripts (excluding the removed server script), 28 checked-in tool pages, 5 route-wrapper generator inputs, 14 browser workbench/persistence modules, 17 Worker files (including 4 migrations). The 256 generated tool pages materialize during `npm ci`; they are not independent hand-written configuration files. The path-level annexes [`paths-1`](native-first-559-paths-1.md), [`paths-2`](native-first-559-paths-2.md) and [`paths-3`](native-first-559-paths-3.md) enumerate every one of these source paths. `NATIVE` means native mechanism already used; `REPLACE` means a redundant wrapper removed here; `GAP` means remaining application or verification behavior is additional to the platform feature. `REVIEW` means a candidate still needs inspection before its final class is known. Classification of script orchestration is still under review, as called out below.
