Evidence key: target release/branch source digest, backend/worker digest, compiled assets, manifest/tool/engine identity, fixture hash, browser engine/build, device model/OS/browser, timestamp, exact test command, artifact/output hash, witness/runner, format/input class, verdict and limitations. ## CI and verifier contract — future tickets only

1. **Fast static PR gate:** registry/manifest ID and route uniqueness; `npm run tickets:check`; format/operation coverage; issue/AC/OWN links; Markdown links; graph acyclicity; source/licence data versioning; affected release-preview visibility gates; scoped typecheck/lint; no network/deploy/secrets. Fail closed on parsing errors. Historical receipts are read-only inputs.
2. **Change impact graph:** map source files and installed pinned assets to affected tool IDs, engine families, worker/backend, runtime, oracle families and consumer/browser acceptance. Changes to `worker/`, migrations/auth, public WASM, or CSP invalidate the appropriate scopes. A shared engine change fans out to its actual consumers. `git diff` alone is insufficient for dependency resolution; compare content SHA and dependency closure.
3. **Per-batch source validation:** impacted unit/fixture/oracle checks plus independent output parser/reader and malicious cases; plan/contract source packs verified by SHA and legal effective-date boundary. Compare results with pre-change reference; admit intentional behavior change only with versioned spec and updated oracle independently created.
4. **Browser matrix:** Chrome/Chromium desktop; WebKit and Firefox engine runs where available; widths 320/390/768/1024/1440, light/dark, keyboard, touch or equivalent, 200% zoom and reduced motion. Every newly accepted route must complete file-picker→operation→preview→download/reopen or report a typed refusal, with cancel and recoverable quota/unsupported cases. Desktop mobile viewport is labeled desktop.
5. **Native physical lanes:** iOS Safari on a real paired/unlocked device (Web Inspector or bounded manual witness) and Android Chrome on a real reachable device. A simulator, Playwright mobile emulation or WebDriver mock capture never clears `physical*`. Record model, OS, browser, source revision, input SHA, proof of real Files/Photos picker, operation, actual share/download and reopened data, permission/cancel/crash/memory, screenshots with no PII. Unavailable device means `EXTERNAL/NOT_RUN`, not skipped PASS.
6. **Security/privacy lane:** adversarial PDFs, signature/xref/object streams, hidden metadata and orphan objects; encrypted/corrupt/hostile SVG/Office/ZIP/EPUB; traversal/bombs/inflate ceilings, permission denial, malformed and oversized files, cancel, secret-safe logs, zero unconsented content transfer. A source parser's success is not a security oracle. Require independent output validator/renderer and reviewed provenance for security claims. Redaction-specific signoff is mandatory prior to public route or badge.
7. **Release candidate integrated:** all accepted changed scopes have compatible current receipts; manifest and badge status computed from same verified identity; full clean candidate test/check/build, output reopen smoke for each changed family, HTML/meta/SEO and preview-only exclusions, identity of server+assets+worker, real telemetry consent flows, accessibility and privacy/retention claims audited, physical blockers explicitly scoped. Reviewer signs a per-scope *release* candidate, not global future-product parity.
8. **Promotion & rollback:** named build/asset hashes, Cloudflare preview/canary IDs, worker+migration schema forward/backward compatibility, zero silent file-upload fallback, explicit release owner gate, canary service/route smoke and independent downloaded-artifact reopening. Record rollback rehearsal and data compatibility on preview/isolated environment. If any mandatory gate FAIL/STALE/NOT_RUN, hold that scope, do not alter receipts/checklists to pass.
