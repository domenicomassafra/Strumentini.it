# #241 PDF visible signature — cancellable Worker / safety acceptance

Run: 2026-10-10, worker-6, local Mac. Scope: bounded unsigned PDF graphic overlay only. This is **not** a cryptographic/digital signature and proves no legal validity.

Owned source changes: `src/components/tools/pdf/PdfVisualSignature241Tool.tsx`, `src/engines/pdf/visual-signature-worker-241.ts`, `src/engines/pdf/visual-signature-worker-client-241.ts`, `tests/pdf-visual-signature-ui-241.browser.ts`, and `tests/pdf-visual-signature-241.test.ts`.

The signed-looking graphic is placed as a page-content image on explicitly chosen pages with the original page streams and geometry checked after rewriting. There is no `/FT /Sig`, certificate, electronic seal or encryption bypass. The source is transferred only as copies to a disposable same-origin browser Worker; original input bytes remain available to the independent PDF.js reopening check. The Worker is terminated on AbortSignal/error/completion/45-second timeout, and a file cannot be downloaded until PDF.js reopens and renders every selected page.
