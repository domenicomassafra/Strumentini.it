## 2026-10-08 implementation + verification (core DONE; UI pending; NOT Gold)

- **Engine:** `src/engines/ooxml/media-compress.ts`, separate from PDF and existing OOXML writer. Uses the existing `analyzeOoxmlPackage` bounded ZIP preflight and `fflate` DEFLATE rebuild. Output is reanalyzed and unzipped, and **every non-media member is byte-identical**, including every `*.rels`, `[Content_Types].xml`, editable document/slide/sheet XML and member paths. Content-type declarations are inspected before media selection; no relationship/part paths are rewritten or external targets resolved.
- **Codec/fidelity:** only actual `word/media`, `ppt/media`, or `xl/media` PNG/JPG/JPEG with matching signature and declared MIME may change. PNG without resize uses browser Canvas re-encode and independently compares decoded RGBA bytes (same-browser pixel equality; **ICC/profile/metadata bytes are not promised unchanged**). JPEG requires explicit `approveLossyJpeg: true` and controlled quality 0.35–0.90, else skipped. Image downsizing requires separate `approveResize: true` plus `maxDimension`; visible dimensions and loss/fidelity reported. The injectable codec is only a testing seam; when used, the result says `pngDecodedPixelsIdenticalUnlessResizeApproved: not-proven-custom-codec`, never claiming browser pixel proof for a codec it did not verify. Failed/unavailable codecs leave media unchanged; decoded output must retain exact MIME/dimensions and be **smaller** before replacement. If the final OOXML ZIP is not smaller, return original bytes with `package-not-smaller` skips.
- **Hard limits:** existing package max 20 MiB input/2,048 entries/40 MiB combined expanded bytes/ratio 100; media transform max 16 candidates, 8 MiB image bytes each, 4,096 pixel dimension and 12 million cumulative decoded pixels, with bounded options and AbortSignal. ZIP macros, encryption, traversal, ambiguous content types and unsupported image codecs fail closed or skip as appropriate; no cross-format relabeling.
- **Genuine fixtures:** `tests/ooxml-media-generate-fixtures.py` deterministically builds real editable DOCX (python-docx), PPTX (python-pptx) and XLSX (xlsxwriter) with two embedded images made with Pillow. The media PNG intentionally starts without compression and the JPEG is high quality, so savings are measured on actual Office-owned media rather than fabricated ZIP-only tests. Original files live in `tests/ooxml-media-fixtures/`.
- **Node independent-codec oracle:** `tests/ooxml-media-264.test.ts` tests real PNG pixel equality via Sharp decoding, opt-in JPEG quality, relationship/XML/member equality, resize approval, malware ZIP input, ambiguous types and abort; `tests/ooxml-package-rebuild.test.ts` covers existing writer.
- **Real browser acceptance:** `node tests/ooxml-media-264.browser.mjs` packages the **actual engine** with esbuild, runs it in real desktop headless Chromium via local HTTP, downloads real `.docx/.pptx/.xlsx` Blob artifacts and checks members/relationships independently. `tests/ooxml-media-264-independent-reopen.py` then uses the separate Python ZIP parser plus `python-docx`/`python-pptx` and XLSX XML/drawing checks to reopen the downloaded files. Browser evidence and the three **real generated OOXML files** are in `tests/ooxml-media-receipts/`, with SHA-256 and per-part changed/savings.
- **Observed original → real-browser output:** DOCX **200,848 → 74,753 B** (126,095 B saved), PPTX **192,206 → 66,832 B** (125,374 B saved), XLSX **170,476 → 44,705 B** (125,771 B saved); both JPEG and PNG optimized after explicit JPEG approval. 33/33 Chromium browser acceptance checks PASS with no offsite requests; no physical device/browser matrix claims. Focused legacy writer + media tests and TypeScript type checks also validated; see commit receipts.

The generic ZIP Contents Inspector and its historical Gold scope remain untouched. File selection is DOCX/PPTX/XLSX only; JPEG lossy re-encode and resizing have **separate unchecked-by-default consent controls**; quality and maximum dimensions are explicit; cancellation/reset, results, per-media status/skip reasons/net savings/fidelity, Result-v2-style verified Office artifact and download are rendered locally. The output artifact descriptor is declared verified **after** OOXML preflight/independent member comparison; this is not a Gold certificate.
