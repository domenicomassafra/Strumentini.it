# 246 — Local image OCR

**What to build:** Implement local OCR for supported image formats/languages after the OCR feasibility gate, exposing language, confidence where provided and page/image provenance without cloud upload.

**Traces to:** US-EXP-04, US-EXP-06, US-EXP-09; AC-06.1

**Constraints:** C-EXP-01, C-EXP-04, C-EXP-05, C-EXP-08; local-first, explicit fidelity limits, verified output, lazy heavy dependencies.

**Blocked by:** 100, 103, 206, 271.

**Status:** ready-for-agent

**Suggested skills:** code-module-design → code-tdd → qa-browser → browser-performance-benchmark

- [ ] Italian OCR is an explicit supported language when accepted.
- [ ] Confidence is shown only if engine provides meaningful confidence.
- [ ] Large/unsupported images fail preflight rather than crash.

The new separate `src/engines/ocr/local-italian-246.ts` uses existing #246 CRC-checked PNG header/size/pixel/worker/WASM preflight, then native image decoding to verify the real dimensions before loading the worker. **Only** PNG/`ita`, ≤5 MiB, ≤2 MP and ≤4000 pixels per side are supported; unsupported payloads fail before runtime/model initialisation. Active AbortSignal cancels the job and calls `worker.terminate()`, including eventual teardown after late worker initialization; duration is bounded (default 90 seconds). The worker terminates after success or failure, and an invalid/nonfinite score is `null`, never invented; finite scores are explicitly labeled *uncalibrated Tesseract engine indicators*. This is an independently functional local OCR engine, not a change to the existing `image-feasibility.ts` production-REFUSED contract.
