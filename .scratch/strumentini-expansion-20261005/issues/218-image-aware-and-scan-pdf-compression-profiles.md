**2026-10-08 narrowly scoped embedded-JPEG addition (partial #218):** `src/engines/pdf/jpeg-image-aware.ts` adds an explicit opt-in `jpeg-rgb-reencode` path, exposed via the PDF compression screen while the original structural-only mode stays the default. It decodes/reencodes directly referenced PDF Image XObjects only when they are single-filter `/DCTDecode`, `/DeviceRGB`, 8-bit, unmasked baseline-compatible JPEG with dimensions matching the JPEG header; browser JPEG encoder quality is bounded 0.35–0.85, no image is enlarged, and the output is returned as the original when whole-PDF rewrite grows in size. Source image stream decisions (recompressed/skipped and reasons), changed JPEG byte sizes, page geometry, extracted text, and byte-for-byte page `/Contents` checks are recorded or enforced. Fixture-backed tests use actual high-quality JPEG bytes re-encoded with a real image codec and compare PDF sizes, text, embedded JPEG bytes and approximate decoded pixels (lossy). Unsupported images (PNG, JBIG2, masks, ICC/CMYK etc.), DPI-based downsampling, grayscale, arbitrary PDF semantic equivalence, multi-browser physical-device performance and a large mixed-document corpus remain OPEN; this is NOT full image-aware/scan feature completion or Gold evidence.

**2026-10-09 opt-in scan Flate tranche (partial #218; ticket stays OPEN):** Added separate `scan-flate-to-jpeg` profile via `src/engines/pdf/scan-image-aware.ts` and the existing PDF compression UI. Converts directly referenced, unmasked, 8-bit `/FlateDecode` RGB and Gray image streams to lossy RGB JPEG using browser canvas. Supports bounded raw, TIFF horizontal and PNG predictors, explicit maximum image longest edge (256–4096 pixels) and optional grayscale pixels; it deliberately **does not infer or claim effective document DPI**, preserve lossless original pixels, or affect source text/vector page content. Native streaming Flate decompression is capped by expected pixel dimensions; complex masks, extra dictionary operators, JPEG/JPX/JBIG2, unsupported predictors and unreferenced assets are skipped with per-object reasons. Each successful output is reparsed, the source/output extracted text, page geometry and exact page `/Contents` bytes are compared, and the original is returned if a whole-document rebuild would grow. UI reports actual images touched/skipped, requested/effective edge and grayscale settings, and keep-original recommendation. `tests/pdf-scan-image-aware-218.test.ts` plus existing #218 suites: **16/16 PASS**. `npm run acceptance:pdf-image-aware` **PASS** on freshly built static output at 390px Chromium: Flate scan sample **222263 B → 13081 B**, 320×240 → 256×192 image, actual grayscale RGB JPEG; PDF.js independently re-rendered both source and output at 320×300, text stayed extractable, and existing JPEG path remained green. `npx astro check`: 0 errors; `npm run build`: 284 pages PASS. Missing: true placement-DPI estimation and DPI policy, broader real-world scan/mixed image corpus, PDF/X complex structures and non-page stream semantics, physical-device/mobile-memory and multi-browser acceptance, and full Gold evidence. No production promotion/Gold claim.
