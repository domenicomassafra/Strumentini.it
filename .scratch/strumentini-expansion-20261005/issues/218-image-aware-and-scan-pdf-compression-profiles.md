**2026-10-09 opt-in scan Flate tranche (partial #218; ticket stays OPEN):** Added separate `scan-flate-to-jpeg` profile via `src/engines/pdf/scan-image-aware.ts` and the existing PDF compression UI. Converts directly referenced, unmasked, 8-bit `/FlateDecode` RGB and Gray image streams to lossy RGB JPEG using browser canvas. Supports bounded raw, TIFF horizontal and PNG predictors, explicit maximum image longest edge (256–4096 pixels) and optional grayscale pixels; it deliberately **does not infer or claim effective document DPI**, preserve lossless original pixels, or affect source text/vector page content. Native streaming Flate decompression is capped by expected pixel dimensions; complex masks, extra dictionary operators, JPEG/JPX/JBIG2, unsupported predictors and unreferenced assets are skipped with per-object reasons. Each successful output is reparsed, the source/output extracted text, page geometry and exact page `/Contents` bytes are compared, and the original is returned if a whole-document rebuild would grow. UI reports actual images touched/skipped, requested/effective edge and grayscale settings, and keep-original recommendation. `tests/pdf-scan-image-aware-218.test.ts` plus existing #218 suites: **16/16 PASS**. `npm run acceptance:pdf-image-aware` **PASS** on freshly built static output at 390px Chromium: Flate scan sample **222263 B → 13081 B**, 320×240 → 256×192 image, actual grayscale RGB JPEG; PDF.js independently re-rendered both source and output at 320×300, text stayed extractable, and existing JPEG path remained green. `npx astro check`: 0 errors; `npm run build`: 284 pages PASS. Missing: true placement-DPI estimation and DPI policy, broader real-world scan/mixed image corpus, PDF/X complex structures and non-page stream semantics, physical-device/mobile-memory and multi-browser acceptance, and full Gold evidence. No production promotion/Gold claim.

**2026-10-09 additional image-aware safety and memory tranche (OPEN):** New isolated `src/engines/pdf/image-aware-safety-218.ts`, used by the existing JPEG and Flate-to-JPEG profiles, detects page-level compositing dependencies that cannot be certified merely by preserving the original page `/Contents` bytes: nonempty `/ExtGState` (including blend modes), page `/Group`, resource `/Pattern` or `/Shading`, nested Form XObjects, unsupported XObject graphs, and indirect image `/SMask` or `/Mask`. Both profiles now **fail closed for the whole affected document**, return original PDF bytes unchanged, count `touched=0`, and attach explicit skipped-object reasons. Already-supported direct unmasked JPEG/Flate transformations remain enabled on documents without those compositing risks. The scan Flate decoder now decompresses into **one preallocated, dimension-bounded output buffer** instead of keeping every expanded chunk and then duplicating the complete raster; it checks cancellation between reads and actively cancels the stream reader. Temporary encode/downsample canvases are resized to portable 1×1 in `finally` to free pixel backing stores (native Node Canvas turns a zero-sized canvas back into 350×150).

**Independent mixed-XObject proof:** `tests/pdf-image-aware-safety-218.test.ts` builds genuine parseable PDFs containing JPEG, Flate RGB, a linked grayscale soft mask, vector text, and an actual `/ExtGState /BM /Multiply` page resource, plus Group/Form/Pattern variants. The new safety gate returns original bytes with unchanged object JPEG/Flate stream SHA-256 fingerprints and page geometry/text; source/output are separately rasterized by real PDF.js and native Canvas, and decoded output PNG pixels are compared byte-for-byte by Python Pillow. Original JPEG bytes are independently reopened with sharp and compressed Flate images decoded by Node zlib. A separate permitted mixed JPEG + Flate PDF compresses **83,352 → 32,393 bytes**, preserves page vector text and yields a PDF.js-rendered RGB average absolute pixel delta of **12.24** (lossy, not visual equivalence); the written JPEG is independently reopened with sharp. A deliberately overexpanding Flate stream is refused before canvas allocation; pre-cancelled operations stay abortable. New + existing #218 tests **23/23 PASS**; targeted TypeScript and Git whitespace checks **PASS**. These are desktop/Node proof only; no browser replay or physical iOS/Android acceptance was run in this tranche.
