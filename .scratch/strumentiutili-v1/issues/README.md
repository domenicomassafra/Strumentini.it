# Historical ticket archive

The files in this directory are the original StrumentiUtili.it v1 validation tickets. They are retained for traceability only.

They are **not** an active queue, even where an individual ticket still contains wording such as "ready", "current", "blocked", or agent instructions. Reconcile any useful historical requirement against the current authorities before acting:

1. `/PROJECT-STATUS.md`
2. `/HANDOFF.md`
3. `/ROADMAP.md`
4. `/quality/receipts/expanded-catalog-certification.json`

The original Image Resize physical-device requirement remains a real external evidence boundary, but the old ticket file is not the operational owner of that work.
